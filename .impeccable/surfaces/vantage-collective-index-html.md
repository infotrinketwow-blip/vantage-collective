## Scope

Persuade — single-page marketing/landing site for the fictional agency Vantage Collective, at `vantage-collective/index.html`. Audience: agency-fatigued marketing buyers (Pressure Cooker CMO, Modernizer Marketing Director). Job: read the page cold, believe the agency is different, act (start a sprint / request an audit / pick a fight with their category).

## Note on world selection

The commissioning brief pins the visual world exhaustively and literally: exact hex palette (near-black #0A0A0A, paper #F2EFE9, blood-red #D91E2B, acid-lime #E8FF6B), exact type pairing (oversized condensed display + technical grotesk/mono), a named aesthetic ("punk poster / brutalist editorial") with a named reference system (styles.refero.design's "Impossible Foods"), and a full animation spec (parallax layers, one pinned section, staggered collage reveals, scroll-reactive nav, one peak moment, stamp-style CTA). No image generation is available in this environment (context.mjs reported no image-gen tool) and no interactive question mechanism exists in this subagent session, so the concept-seed dice-roll and decision-page round are not run: per new-work.md, "a user- or brief-pinned direction beats the roll, always," and this brief pins every field the roll would otherwise decide. Build path is code-led (no image generation available). This substitution is disclosed to the requesting user in the final report.

## THESIS

The page refuses the safe agency-pitch deck: instead of a clean SaaS-marketing shell, it is built as a torn-poster wall being assembled in front of you as you scroll — headlines slammed down like stamped bills, proof stapled on like receipts. The category default (soft gradient hero, rounded cards, pastel trust badges) is the enemy; this page is loud, asymmetric, and inked.

## OWN-WORLD

Near-black (#0A0A0A) ground, off-white paper (#F2EFE9) panels, blood-red (#D91E2B) as the dominant structural accent (rules, stamps, underlines, 30-40% of ink), acid-lime (#E8FF6B) reserved for single high-value hits (the peak section, active nav state, hover flash). Headlines in an oversized condensed display face (Anton) run in all-caps per the supplied copy; body/labels/nav/eyebrow text in a technical mono/grotesk (Space Grotesk for body, IBM Plex Mono for labels/eyebrows/data). Torn-paper edges (clip-path jagged polygons), halftone dot fields (radial-gradient/SVG pattern), gaffer-tape corner accents, rotated/overlapping panels on an asymmetric grid, thick 2-4px rule lines, stamped/rotated badges.

## STORY

Visitor lands mid-provocation ("YOUR AGENCY IS BORING YOU TO DEATH"), recognizes their own agency fatigue (problem section, torn-deck motif), hears the different mechanism (sprint/POV/dashboard promise), sees it proven (case-study receipt cards), watches the process demystified (pinned corkboard sprint-step section), gets their objection pre-empted (board-risk stress-test), sees social proof (newsprint logo wall + founder quotes), and hits a final stamped CTA wall.

## FIRST VIEWPORT

Full-bleed near-black hero. Fixed/parallax torn-poster-collage background layers (paper scraps, halftone texture, red tape strip) drifting at different scroll speeds behind the headline. Oversized "YOUR AGENCY IS BORING YOU TO DEATH." set in Anton, off-white, occupying the upper-left two-thirds, slightly rotated/staggered per line like torn paper being placed. Subhead in mono beneath. Primary CTA ("Start the Sprint") as a stamped red button, bottom-left; secondary text link near it. A scroll-reactive nav bar (transparent over hero, solidifies to near-black with red rule on scroll) sits fixed at top. Small acid-lime "est." tag or rotated badge in a top-right corner for immediate texture.

## FORM

Chosen form: torn-poster / brutalist-editorial collage system, held as the single brief-pinned direction (no seed key — concept-seed round not run; see "Note on world selection" above).
